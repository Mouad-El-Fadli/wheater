1️⃣ Objectif de l’application

Cette application web permet à l’utilisateur de :

Choisir une ville marocaine

Envoyer le choix via un formulaire

Récupérer les données météo en temps réel depuis une API

Afficher :

la température

la description du climat

un message adapté selon la température

👉 Tout se fait dans une seule page PHP (front + back).

2️⃣ Structure générale de la page

La page contient 3 parties principales :

HTML + CSS → interface utilisateur

Formulaire HTML → envoi de la ville

PHP + API + JSON → récupération et traitement des données météo

3️⃣ Partie HTML & CSS (Interface utilisateur)
🎨 Design

Utilisation de Bootstrap 5 pour le style

Image de fond météo (nuages)

Le formulaire est centré verticalement et horizontalement
